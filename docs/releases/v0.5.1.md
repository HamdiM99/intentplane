## intentplane 0.5.1: `uvx intentplane-mcp`

The MCP proxy command is now its own PyPI package, **`intentplane-mcp`**, which depends on `intentplane[mcp]`.
MCP clients can run it without installing anything first:

```bash
uvx intentplane-mcp --config intentplane.toml
claude mcp add intentplane -- uvx intentplane-mcp --config /path/to/intentplane.toml
```

`server.json` describes the server (`io.github.HamdiM99/intentplane`) for the official MCP Registry.
The `intentplane` package itself is now the library only: `pip install intentplane-mcp` for the command.
