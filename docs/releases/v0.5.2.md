## intentplane 0.5.2: confirm what will actually execute

When an operation needs the user's confirmation (step-up), the MCP client now shows the **resolved** operation:
the trusted record each critical argument resolved to, where it comes from, and amounts in their own units,
instead of the agent's own wording. The user approves what will execute, not the agent's narrative.

```
intentplane: confirm demo.send_money with
{"recipient": "FR7630006000011234567890189  (from beneficiaries/acme)", "amount": 1240.0}
```

Also new: `examples/mcp/demo_client.py`, a narrated run of the demo that needs no MCP client
(`python examples/mcp/demo_client.py`).
